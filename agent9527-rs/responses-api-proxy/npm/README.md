# @tkpdx01/agent9527-responses-api-proxy

<p align="center"><code>npm i -g @tkpdx01/agent9527-responses-api-proxy</code> to install <code>agent9527-responses-api-proxy</code></p>

This package distributes the prebuilt [Agent9527 Responses API proxy binary](https://github.com/tkpdx01/agent9527/tree/main/agent9527-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/agent9527-responses-api-proxy.js --help
```

Refer to [`agent9527-rs/responses-api-proxy/README.md`](https://github.com/tkpdx01/agent9527/blob/main/agent9527-rs/responses-api-proxy/README.md) for detailed documentation.
